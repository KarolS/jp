# Various tools for learning Japanese

## Userscripts

Install those using Tampermonkey or a similar extension:

* [JPDB show all occurences](./jpdb_show_all_occurences.user.js) – on JPDB vocabulary pages, shows the number of occurences in your decks of the current word

* [Hide Chinese Pixiv novels](./hide_chinese_pixiv_novels_on_google.user.js) – when searching for Pixiv novels on Google, hide Chinese novels
