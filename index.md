# Various tools for learning Japanese

## Userscripts

Install those using Tampermonkey or a similar extension:

* [JPDB show all occurences](./jpdb_show_all_occurences.user.js) – on JPDB vocabulary pages, shows the number of occurences in your decks of the current word

* [Add JPDB/Jiten/Kotobank links to jisho.org](jisho_jpdb_jiten_kotobank_links.user.js) – on Jisho.org search result and vocabulary pages, adds links to corresponding entries in JPDB and Jiten, and links to search results in JPDB, Jiten and  Kotobank  

* [Add Epubs as new jpdb.io Decks](./etj.user.js) – adds a functionality for importing epubs to JPDB (port of a Chrome extension by renjixd)

* [Hide Chinese Pixiv novels](./hide_chinese_pixiv_novels_on_google.user.js) – when searching for Pixiv novels on Google, hide Chinese novels

## MPV scripts

Install those into the `lua` directory of your MPV installation

* [Subtitle autocopy](./autocopy.lua) – automatically copies the current subtitle into the clipboard. Requires MPV 0.40 or newer.
